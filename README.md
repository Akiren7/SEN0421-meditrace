# MediTrace

IEC 62304-compliant medical device data management system — **SDS-02**, Software Development with Standards (SEN0421), Istanbul Kültür University.

MediTrace collects simulated vital signs (heart rate, blood pressure, SpO₂), validates and stores them encrypted, raises smart alarms and logs hazardous events. Development follows **IEC 62304** (Class B) and **ISO 14971**.

## Working rules (IEC 62304 Clauses 8–9)
- `main` is protected: changes arrive only through pull requests with at least one approval.
- One issue per task; branch name `feature/REQ-xxx-short-name` or `fix/<issue-number>-short-name`.
- Commit messages start with the traced ID when there is one, e.g. `REQ-002: add plausibility range check`.
- Defects are reported with the *Bug / anomaly* issue template and closed only after a verifying test.

## Identification scheme
`REQ-xxx` requirement · `RISK-xxx` risk · `RCM-xxx` risk control measure · `ARC-xxx` component · `TC-xxx` test case

> Educational project. No real patient data is used; all data is generated by the simulator.
